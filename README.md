# Investment Banker Mode

> **Your decisions move the money. The market decides your fate.**

A financial career-management game. You join **Apex Capital** as Head of Investments with **₹100 Cr**, a
**₹112 Cr quarterly target**, a **10% drawdown limit** and **90 days**. The market is simulated hour by hour
on an Indian-style exchange. Your trades, your time, your risk calls and your conduct decide whether you are
promoted, warned or fired.

> **This is a game.** Every company, index, price, person and news event is fictional and generated by the
> simulation. Nothing here is live market data or financial advice. Names were chosen to avoid real
> companies and index trademarks: the benchmark is **BHARAT 50**, not a real index; the exchange is the
> fictional **Dalal Street Exchange (DSX)**.

## Quick start (local, no Docker)

Requirements: Python 3.10+ and Node 20+.

```bash
# 1. Backend (SQLite by default: no database setup needed)
cd backend
python -m venv .venv
.venv/Scripts/activate            # Windows  (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000

# 2. Frontend (new terminal)
cd frontend
npm install
npm run dev                       # http://127.0.0.1:5173
```

The Vite dev server proxies `/api` to `http://127.0.0.1:8000` (override with `API_TARGET`).

## Quick start (Docker, PostgreSQL)

```bash
docker compose up --build -d      # frontend http://localhost:5173 · API :8000
docker compose logs -f backend    # follow server logs
docker compose down               # stop (add -v to also wipe the Postgres volume)
```

PostgreSQL runs inside the stack and is not published to the host, so it won't clash with a local Postgres
on 5432. The first page load is slower while Vite pre-bundles dependencies.

Set `DATABASE_URL` to use any other PostgreSQL instance
(e.g. `postgresql+psycopg2://user:pass@host:5432/db`).

## How to play

| Control | What it costs | What happens |
|---|---|---|
| **BUY / SELL STOCK** | no time | Market order: live price + market impact (large orders move the price) + fees |
| **RESEARCH** | 1 h quick · 3 h deep dive | Noisy fair-value estimate, results view; deep dives can uncover hidden red flags |
| **WORK 1 HOUR** | +1 h | One simulated market hour |
| **SKIP 2H / 4H / TO CLOSE** | +n h (stops at 17:00) | Every skipped hour is fully simulated |
| **NEXT BUSINESS DAY / SKIP WEEKEND / NEXT WEEK** | to next 09:00 open | Overnight and weekend news gap into the open; you get a daily or weekend report |
| **TAKE LEAVE** | 1, 3, 5 or custom business days (60/year) | The market keeps moving. At Level 1 nobody manages your book while you're away |
| **LIVE ▶ (1× / 2× / 4×)** | real time | The clock runs by itself; charts draw live, 5-minute ticks inside each hour |

Things to watch:

- **Risk policy (MEDIUM profile):** max 15% in one stock, 40% in one sector, 10% drawdown. A breach raises a
  blocking **RISK WARNING**: *reduce exposure*, *request an exception* (the Chief Risk Officer decides) or
  *ignore* it (it goes on your record).
- **Block deals** arrive with a discount and a deadline. Some sellers know bad news is coming. A 3-hour deep
  dive might reveal it, if you have 3 hours before the offer expires.
- **Scheduled events**, including CPI, GDP, the central-bank decision, company results and CEO check-ins,
  are in the calendar. The economist's forecast is better than the consensus, but not perfect.
- **Compliance:** buying more than 8% of the book with no research or thesis on file earns a strike.
- **Quarterly review:** you're scored on return vs target, drawdown, risk conduct, reputation, alpha vs
  BHARAT 50 and decision quality (were your recorded theses right?). The possible outcomes are
  PROMOTED, TARGET ACHIEVED, WARNING, FAILED or TERMINATED. Warnings escalate:
  WARNING → FINAL WARNING → TERMINATED. A drawdown of 20% or more ends the career at once.

## What's implemented

**Simulation (Python, authoritative)**
- **TimeEngine:** real calendar (09:00–17:00, weekends, quarters, career years). Every skip or leave day
  runs through the same per-hour hooks.
- **Market engine:** a multi-factor model. The hidden regime (BULL, STABLE, VOLATILE, BEAR, CRISIS) sets
  drift, volatility and event rates. On top of it: sector factors with macro sensitivities (rates, oil,
  global risk appetite, INR), fundamentals, mean reversion to a hidden fair value, sentiment, momentum,
  institutional flows, event jumps, and fat-tailed noise. Each hour has 12 × 5-minute ticks. Eight
  simulated tickers are derived from these: BHARAT 50, DALAL 30, BHARAT BANK, BHARAT VOL, USD/INR, GOLD,
  US TECH 100 and US 500.
- **20 fictional companies** in 11 sectors, randomised per career seed. There are 45 days of pre-game
  history, so charts are never empty.
- **Event engine:** about 15 company event types, 7 macro, 7 market, plus scheduled earnings and data
  releases. **Branching multi-day chains** run over several days, for example acquisition → analyst
  doubts → debt concerns → rating downgrade or financing secured. Every event produces news and changes
  market state.
- **Portfolio and risk:** fees, transaction tax, liquidity-based market impact, realised and unrealised P&L,
  drawdown, volatility, beta, VaR, concentration, and consequences for breaches.
- **Career:** 7-level ladder. Level 1 is fully playable; promotion continues the career into the next
  quarter with the same machinery, adding capital and new targets. Also reputation, XP, the warning
  ladder, achievements and a major-decision log.
- **Characters:** CEO, CFO, Chief Risk Officer, Research Director, Senior Analyst, Head Trader, Economist,
  Compliance and HR. Each has skills with real effects: research accuracy, execution impact, exception
  odds and forecast quality. Each also has trust and stress that react to your choices.
- **Save/load:** named save slots roll history back consistently. Autosave runs after every action;
  refreshing the browser or restarting the server resumes exactly where you were. The RNG state is
  persisted, so a seed reproduces its market.

**ML (behind the scenes)**
- Player-behaviour features → classifier (CONSERVATIVE / BALANCED / AGGRESSIVE / SPECULATIVE), hidden from
  the player.
- **Adaptive director:** runs daily and adjusts only market-wide dials (event intensity, block-deal
  frequency, small regime tilts), all within fixed bounds. It never looks at your holdings and never sets
  prices or outcomes. Tests enforce both.
- Rule-based fallback is always available. A trained model in `app/ml/artifacts/` is loaded automatically
  when present, and `IBM_DISABLE_ML=1` forces the rules.

**Frontend (React + TypeScript + Tailwind + lightweight-charts)**
- A cinematic onboarding sequence, then the full-screen terminal: career bar, ticker strip, a live
  candlestick chart with SMA/EMA/Bollinger overlays, portfolio ring, holdings, news, calendar, inbox,
  block deals, and an action bar showing the time cost of every action.
- Screens: Markets screener, Stock detail (candles, RSI, MACD, ATR, fundamentals, research, thesis),
  Portfolio, Research, Trading, News & calendar, Team, Career, Performance.
- Illustrated vector characters (no photographs) in dialogues, reviews and team cards.

## ML pipeline (offline)

```bash
cd backend
python -m app.ml.training.simulate_players --seeds 16   # bots play full quarters -> labelled dataset + balance report
python -m app.ml.training.train_behavior               # grouped-by-seed split, metrics vs rule baseline, saves artifact
pip install -r requirements-ml.txt                      # optional: --model xgb and SHAP importance
```

The trainer refuses to deploy a model that doesn't beat the rule baseline. The latest run scored 88.6% on
held-out market paths, against 59.2% for the rules. Caveat: this is trained on **synthetic bot players**.
Real telemetry (recorded in the `telemetry` table) is what it should eventually learn from.

The same bot runs double as a **strategy balance check** (16 shared seeds):

| Style | Mean return | SD | Hit +12% | Mean max DD | Fired |
|---|---|---|---|---|---|
| Conservative | +0.3% | 5.4% | 0% | 5.2% | 0 / 16 |
| Balanced | +5.1% | 9.5% | 19% | 6.6% | 0 / 16 |
| Aggressive | −0.2% | 15.0% | 25% | 13.4% | 7 / 16 |
| Speculative (ignores risk desk) | +1.6% | 10.7% | 12% | 12.3% | 15 / 16 |

No style dominates. Taking more risk raises both your chance of hitting the target and your chance of
being fired, and reckless conduct gets you fired even when the returns are good.

## Known limitations

- Only Level 1 has bespoke content. Higher levels reuse the same loop with more capital, delegation during
  leave and hiring, but bonds, IPOs, M&A, clients and multiple portfolios are schema and extension points
  only.
- There are no market holidays. The trading day is 09:00–17:00, as the design spec defines it.
- Live mode is client-paced: the browser asks the server to advance one hour at a time. The server stays
  authoritative, but a closed tab pauses the clock.
- The Docker/PostgreSQL path is configured but was not exercised in this build environment. Local runs
  use SQLite.
- The behaviour model is trained on bot data; see the ML caveat above.
